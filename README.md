# 浏览器 WebGPU 超声扫查实训仿真系统

TypeScript + Vite + WebGPU + IndexedDB。系统从 CT 体数据出发，在 WGSL compute shader 中追踪超声声线并实时扫描转换为 B 超，包含病例库、扫查训练、标准切面考核、图像参数、成绩统计/轨迹回放和设置验收六个页面。

## 启动

需要 Node.js 20+ / pnpm。

```bash
npm install
npm run dev
# 或 pnpm install && pnpm dev
```

浏览器请使用桌面版 Chrome / Edge 120+，并确认 `chrome://gpu` 中 WebGPU 可用。若浏览器或无头录制环境没有 WebGPU，系统会自动切换到降精度 CPU 参考内核；此时界面和交互仍可演示，但 512³ / 30FPS 验收必须以 WebGPU 结果为准。生产构建：

```bash
pnpm build
pnpm preview
```

类型检查可单独执行 `npm run typecheck`。

## 已实现需求对照

1. **病例库**：一键合成腹部 CT，支持 256³ 流畅版和 512³ 验收版；支持导入无头 Int16 RAW/BIN CT。HU 分段映射声阻抗、衰减系数、散射强度；可在轴/冠/矢切面上用笔刷改写体素并写回 IndexedDB。
2. **扫查训练**：Canvas 软件三维腹部视图，可直接拖体表移动探头，也可用 X/Y/Z 位置、双轴倾角和旋转滑杆精确控制；旁边实时显示 WebGPU B 超。
3. **声学仿真**：自写 WGSL compute shader，256 声线 × 1024 深度步；包含阻抗界面反射、透射、累计衰减、声影、液体低衰减导致的后方回声增强、延迟重复回波混响，以及锁定在 CT 世界坐标中的相干散斑。
4. **探头类型**：线阵矩形声场、凸阵圆弧声场、相控阵原点扇扫；扇面夹角、曲率和深度坐标一致。
5. **图像参数**：总增益、八段 TGC、深度、焦点相关横向声束宽度、动态范围、频率、扇角和散斑强度，调整后下一帧生效。
6. **标准切面考核**：内置肝脏横切、胆囊长轴、右肾冠状、左肾冠状四类题目；冻结后比较探头位置误差、声束方向和切面旋转轴，位置 48% + 角度 52% 评分。
7. **成绩统计**：成绩存 IndexedDB，可按学生和题目汇总次数、正确率、平均分和平均用时，也可按学生/题目筛选明细。
8. **录制回放**：训练和考核会按 10Hz 记录探头六自由度轨迹；成绩统计页可打开回放弹窗，同步播放三维路径、探头姿态和 B 超。

## 合成体数据与验收口径

合成数据包含肝、双肾、肾窦、胆囊、腹主动脉、下腔静脉、六对弧形肋骨，以及一块 HU=3000 的强反射标定板。

- 体素间距：`0.625 mm`
- 512³ 物理边长：`320 mm`
- 标定板第一表面世界坐标：`y = 120 mm`
- 标定探头声原点：`[160, 40, 165] mm`
- 期望界面声程：`80 mm`

打开 **设置验收** 页：

- 点击“执行 <0.5mm 深度验收”：自动准备 512³ 数据、dispatch compute、回读中心两条声线，并用抛物线亚采样计算峰值深度，显示实测误差。
- 点击“执行 512³ / 3 秒帧率测试”：预热后连续统计三秒 rAF 帧率。目标为不低于 30 FPS。

声学最大模拟声程固定为 `180 mm`，每步 `180 / 1024 = 0.1758 mm`，深度坐标按 `(sample + 0.5) * step` 标定；峰值再做亚采样修正。

## RAW CT 导入约定

当前支持无头原始二进制体数据：

- 体素顺序：x 最快，然后 y，然后 z；
- 推荐 Signed Int16，像素值为真实 HU；
- 也支持 `HU = Uint16 - 1024` 的编码 Uint16；
- 在导入表单填写 `NX/NY/NZ` 和各向同性 spacing。

DICOM 序列可先用 3D Slicer / Horos 导出为 Int16 RAW，或后续扩展 DICOM parser。

```text

src/ui/         三维体表、参数控件、B 超面板、回放弹窗
src/pages/      六个路由页面
src/styles/     设计 token 与页面样式
```

## 数据存储

IndexedDB：`ultrasound-training-workbench`

- `cases`：病例元数据和 CT ArrayBuffer
- `scores`：考核成绩与冻结姿态
- `recordings`：探头轨迹
- `kv`：学生名等设置

浏览器清除站点数据会删除这些本地记录。
